## アプリを作り直し、名前を「LINEを最小化して起動」に変更

Windowsへのサインイン時に、LINEを画面に出さず通知領域へ起動する非公式ツールです。v0.3.0では設定アプリとインストーラーを作り直しました。

### 主な変更

- インストール型になりました。Velopackでインストールし、「設定 → アプリ → インストールされているアプリ」に表示されます。アンインストールもそこから行えます。
- 自動で更新します。サインイン時と設定画面で新しいバージョンを確認し、ハッシュを照合してから入れ替えます。
- 自動起動はスタートアップフォルダーのショートカットになりました。Windowsの「設定 → アプリ → スタートアップ」でオン/オフでき、設定画面のスイッチと連動します。本ツールが書くレジストリは、「インストールされているアプリ」に表示するための情報1か所だけです。
- 設定画面を作り直しました。Windows 11の設定アプリに近い見た目で、ライト/ダークとアクセントカラーはWindowsの設定に合わせます。アプリのアイコンも新しくしました。
- 通知領域のアイコンで、接続中と未読がわかるようになりました。LINEのロゴを使ったまま、接続中は灰色に、未読があるときはLINE本来の「N」の印を重ねて表示します。
- アンインストールの確認画面を用意しました。既定ではすべて削除し、「設定とデータを残す」を選ぶと記録を残します。

### 旧版からの移行

「Windows版LINEを通知領域で起動」（v0.2.0-preview.9まで）を使っている場合は、新しいセットアップEXEを開くだけで移行します。自動起動がオンだった場合はスタートアップフォルダーのショートカットに置き換え、旧版のプログラムと、旧版が書いた自動起動の値を削除します。

### 毎回ログアウトされる場合

PC版LINEはQRコードでログインすると、自動ログインをONにしても終了や再起動のたびにログアウトされます。本ツールを使わない通常の起動でも同じです。メールアドレスとパスワード、または「スマートフォンを使ってログイン」でログインしてください。

### セットアップ

Assetsの **WindowsLineStartToTray-Setup-0.3.0-preview.1.exe** をダウンロードして開いてください。ほかのファイルは自動更新用です。コード署名がないため、Windowsの警告が出た場合は「詳細情報」→「実行」を押してください。修正版でのPC再起動は未確認です。
