## 起動時にすでにある未読でも「N」を表示

Windowsへのサインイン時に、LINEを画面に出さず通知領域へ起動する非公式ツールです。

### 今回の修正

preview.1では、起動時にすでにある未読があっても、通知領域のアイコンに「N」が付きませんでした。起動後に届いたメッセージでも、右下の通知と「N」が出ませんでした。

LINEはメイン画面を開いてから未読を数え、新着の通知を出すようになります。これまではメイン画面を一度も表示せずに閉じていたため、この処理が始まっていませんでした。

preview.2では、メイン画面をWindowsの「クローク」機能で画面にもタスクバーにも出ない状態にしてから一度表示させ、LINEが未読の「N」を付けた時点で通知領域へ移します。未読がないときは5秒たったら移します。表示はフォーカスを奪わない方法で行うため、サインイン直後の操作を妨げません。

実機で、起動時に画面とタスクバーのボタンが見えず、起動から約1.5秒後に既存の未読の「N」が付くことを確認しました。起動後に届いたメッセージでの「N」と右下の通知は、まだ確認していません。

### 更新

preview.1を使っている場合は、サインイン時か、設定画面の「更新を確認」で自動的に更新されます。新しく使う場合は、Assetsの **WindowsLineStartToTray-Setup-0.3.0-preview.2.exe** をダウンロードして開いてください。ほかのファイルは自動更新用です。修正版でのPC再起動は未確認です。
