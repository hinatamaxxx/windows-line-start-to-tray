## 起動時の「Connecting to LINE」も非表示に

Windowsへのサインイン時に、LINEを画面に出さず通知領域へ起動する非公式ツールです。

### 今回の修正

「Connecting to LINE」は、LINE本体とは別にランチャーが出す接続画面でした。旧版ではランチャーの表示要求を抑止対象にしていなかったため、この画面が表示されていました。

ランチャーの専用ウィンドウ（SPLASH）を対象に、画面の作成・表示の段階で表示を抑えるようにしました。接続処理はそのまま進めます。監視ループや、待ってから画面を閉じる処理は追加していません。

preview.6の更新プロセスへの引き継ぎと、専用のスタートアップ登録も含みます。

### セットアップ

Assetsの **WindowsLineStartToTray-Setup-0.2.0-preview.7.exe** をダウンロードしてください。

1. LINEを通知領域のメニューから「終了」します。
2. ダウンロードしたEXEを開き、「セットアップ」を押します。旧版からの更新も同じ手順です。
3. セットアップ画面の「LINEを起動」を押し、接続画面が出ないことと、通知領域のアイコンからLINEを開けることを確認します。
4. 都合のよいときにPCを再起動して確認してください。

LINEの自動ログインはONにします。Windowsのスタートアップは、セットアップがWindowsLineStartToTrayをON、LINEをOFFに設定します。

### 検証した範囲

- Microsoft Storeから導入したLINE 26.5.0.3975で、旧版のランチャーがSPLASHウィンドウを表示することを観測しました。
- 修正版の実機起動では、接続画面の表示要求を抑えたログを確認し、起動後20秒間の観測でランチャーとLINE本体の表示イベントが発生しないことを確認しました。
- 模擬テストで、接続画面の作成時の表示指定、同期・非同期の表示要求、更新経路、LINE本体の非表示起動と再表示、対象外ウィンドウの通常表示を確認しました。
- セットアップの埋め込みファイル照合、起動登録・移行・復元のテスト、および実機に配置したファイルのハッシュ一致を確認しました。

**この版でのPC再起動、実際のLINE自動更新の再実行、実機でのアイコンからの再表示とログイン維持は今回未確認です。** プレビュー版として配布します。

コード署名はありません。照合用のSHA256SUMS.txtを添付しています。LINE本体やログイン情報は同梱しません。
