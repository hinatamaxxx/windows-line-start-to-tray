## セットアップ画面と利用案内の説明を見直し

Windowsへのサインイン時に、LINEを画面に出さず通知領域へ起動する非公式ツールです。

### 今回の修正

セットアップ画面、利用案内、READMEの説明を見直しました。

- 「自動ログインをオンにする」の説明に、QRコードでログインすると終了のたびにログアウトされることと、メールアドレスとパスワードなどでログインすることを加えました。
- 「LINEを起動」を押したあとの案内に、ログアウトしている場合はログイン画面が表示されることを加えました。
- 「画面を出さずに、自動起動。」のように助詞で区切って言い切っていた説明を、何をするかが分かる言い方に直しました。
- 設定を元に戻したときの案内から、「フック」という開発用の言葉を外しました。

表示制御の動作はpreview.8と同じです。LINEがログアウトした状態で起動したときは、ログイン画面を隠さずに表示します。ログイン済みの起動では、これまでどおり画面を出さずに通知領域へ移します。修正版でのPC再起動は未確認です。

### 毎回ログアウトされる場合

PC版LINEはQRコードでログインすると、自動ログインをONにしても終了や再起動のたびにログアウトされます。本ツールを使わない通常の起動でも同じです。メールアドレスとパスワード、または「スマートフォンを使ってログイン」でログインしてください。
