## ログアウト時はログイン画面を表示

Windowsへのサインイン時に、LINEを画面に出さず通知領域へ起動する非公式ツールです。

### 今回の修正

これまでは、LINEがログアウトした状態で起動したときもログイン画面を隠して通知領域へ移していたため、ログアウトに気づきにくい状態でした。ログイン画面はメイン画面と同じ種類のウィンドウですが、最大化ボタンがないことで見分け、ログイン画面だけはそのまま表示するようにしました。ログイン済みの起動では、これまでどおり画面を出さずに通知領域へ移します。

### 毎回ログアウトされる場合

PC版LINEはQRコードでログインすると、自動ログインをONにしても終了や再起動のたびにログアウトされます。本ツールを使わない通常の起動でも同じです。メールアドレスとパスワード、または「スマートフォンを使ってログイン」でログインしてください。
